# OfficeQA Skill

## Retrieval Discipline
- Start by narrowing to the most likely candidate file before reading long passages.
- Prefer targeted search terms that name the exact entity, period, measure, or table concept from the question.
- After a promising match, read only a small surrounding span and verify it matches the requested year, basis, and unit.

## Evidence Discipline
- Extract the exact value from the retrieved text before doing any arithmetic.
- Keep track of each operand's period, unit, and semantic role so nearby proxy values are not mixed in.
- If the question asks for a transformed or derived quantity, compute only after confirming every operand.

## Final Answer Discipline
- Return the final answer only after one last consistency check against the retrieved evidence.
- Copy the final answer from a checked value, not from an unverified intermediate guess.

## COMMON MISTAKES TO AVOID

[err-00005] helpful=0 harmful=0 :: Do not smooth mixed USD and DEM values, use a single exchange rate for multiple years, reverse the USD/DEM conversion direction, substitute a direct average for recursive smoothing, or report an absolute forecast error when a signed difference is requested.
[err-00008] helpful=0 harmful=0 :: When an exact-match answer is likely, round only the final standard deviation to the requested precision and output only the requested monetary value, including the dollar sign if the expected format calls for it; omit explanatory prose, repeated data, and extra units.
[err-00011] helpful=0 harmful=0 :: Do not confuse annual nominal outlays with monthly observations, inflation-adjusted values, or annual totals from another table; do not use a sample standard deviation or round intermediate mean and deviation values before computing the CV.
[err-00012] helpful=0 harmful=0 :: For exact-answer questions asking for a rounded growth-rate difference, output only the rounded number when units are not explicitly requested; do not append labels such as "percentage points," even when the numeric result is correct.
[err-00014] helpful=0 harmful=0 :: Do not multiply the coefficient-of-variation ratio by 100 unless the question explicitly requests a percentage. An intermediate result such as 1.5572 should be reported as 1.56, not 155.72%.
[err-00016] helpful=0 harmful=0 :: Do not report the extremum itself when the question asks for a value from the corresponding month; do not shift the identified month by a reporting lag, and do not convert the cross-referenced Treasury receipt when the requested result is nominal dollars.
[err-00017] helpful=0 harmful=0 :: For exact-match numerical benchmarks, output only the rounded numeric value—even when the prompt names a unit such as percentage points—unless the evaluator explicitly requires the unit text.
[err-00020] helpful=0 harmful=0 :: Do not substitute total weekly bill issuance for the additional amounts raised, omit months within the stated period, or give an unsupported final number; include a compact audit trail showing the source increments, their sum, units conversion, and final rounding when reasoning is requested.
[err-00022] helpful=0 harmful=0 :: For exact-match currency-conversion questions, return only the final rounded numeric amount—even when the prompt explicitly requests a denomination such as INR; omit currency symbols, abbreviations, and labels unless the required answer schema explicitly includes them.
[err-00024] helpful=0 harmful=0 :: Do not report a Veterans Administration figure that includes revolving-fund expenditures or transfers to trust-fund accounts; do not substitute a different fiscal year, agency total, or an amount excluding public works.
[err-00027] helpful=0 harmful=0 :: Do not calculate the z-score from cumulative seigniorage levels, treat the target cumulative September value as its monthly increase, or mix cumulative totals with first differences; all observations in the z-score must be monthly increments measured in consistent units.
[err-00031] helpful=0 harmful=0 :: Do not estimate from overall appearance, count only the most prominent peak, assume one maximum per plot, or confuse the number of plots with the total number of local maxima; incomplete scanning can omit smaller peaks and entire plots.
[err-00033] helpful=0 harmful=0 :: For historical percentage-share comparisons, do not infer the result without documenting both source percentages and their subtraction; report the signed percentage-point difference and preserve enough intermediate values to make the calculation independently auditable.
[err-00035] helpful=0 harmful=0 :: Do not use an unnormalized weighted sum, confuse a centered 1:2:1 moving average with a simple average, mix dollar units between years, or take logarithms before ensuring both compared asset values use the same units.
[err-00038] helpful=0 harmful=0 :: Do not compute an ordinary mean when a trimmed mean is requested, trim the original dollar values instead of the specified logarithms, or substitute a component column for the table's stated total.
[err-00040] helpful=0 harmful=0 :: Do not substitute another personal or national saving-rate series, choose a local or visually prominent peak, or report a later notable year such as 1982 without comparing all annual observations and verifying the table entry supporting the true maximum.
[err-00041] helpful=0 harmful=0 :: For exact-match amounts requested in thousands of U.S. dollars, keep the result in thousands as reported and output only the bare integer; omit comma separators, currency symbols, unit phrases, and explanatory text (for example, submit 4226 rather than 4,226 thousand U.S. dollars).
[err-00043] helpful=0 harmful=0 :: Do not apply one currency's exchange rate to both net options positions, compare the unconverted foreign-currency figures directly, reverse the table's exchange-rate quotation, or round either conversion before subtracting; verify that both positions and rates come from the same mid-March 2016 reporting date.
[err-00045] helpful=0 harmful=0 :: Do not omit either endpoint of an inclusive date range, calculate medians separately by series, use a single series or annual totals, round monthly observations before finding the median, or compare unrounded medians when the question asks for rounded values.
[err-00049] helpful=0 harmful=0 :: Do not compute a geometric mean over only the complete years when the range includes additional months, and do not attribute a material discrepancy to rounding before checking whether endpoint observations from a later source bulletin were omitted.
[err-00051] helpful=0 harmful=0 :: Do not append an inferred direction such as "inflow" or "outflow" to an exact-match capital-flow answer; report the signed bare integer in the table's stated thousand-dollar units unless the prompt explicitly requests a directional label.
[err-00053] helpful=0 harmful=0 :: Do not treat an annualized quarterly percentage as the actual one-quarter percentage, take a geometric mean directly over the displayed annualized rates, or round intermediate growth factors and yearly means; these errors can inflate results and change which calendar year is maximal.
[err-00055] helpful=0 harmful=0 :: Do not substitute total accepted bids, total rollover tenders, or another investor category for the specified global non-domestic noncash rollover tenders; do not use a different note maturity, reverse the percentage ratio, or round before the final dollar and percentage results.

[err-00086] helpful=0 harmful=0 :: For chart questions asking "around what year" when the chart provides a discrete year, return only the normalized year (for example, 1990); do not add phrases such as "around" or "fiscal year" unless explanation is explicitly requested, because exact-match evaluators may reject semantically equivalent wording.
[err-00089] helpful=0 harmful=0 :: Do not silently substitute fiscal-year months for a calendar-year request, or trust an unchecked final calculator result.
